# tools/

Developer utilities that are not part of the installable `src/` package.

| Folder | Purpose |
|---|---|
| `docs_build/` | Build helpers for the PDF/HTML reports (`html_to_pdf.py`, `parse_tomtom.py`) |
| `notebook_utils/` | Sanity checks for notebooks (`verify_phase2_pipeline.py`) |

One-off scripts (GitHub comment posting, notebook dumping) are intentionally **not** kept in the repository.
